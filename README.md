## Entry

`main.ts` (Node 22, stdlib only) writes one short rant about an everyday annoyance to `/output/entry.txt`: 1–400 characters, a few sentences at most, no trailing newline, deterministic across runs.

## The rant

One specific, concrete annoyance — the printer, the bus, the person who says "circling back" — ranted about in sharp, economical wording, with the anger feeling shared rather than performed and the laugh landing on the first read. The judge weighs, in order: really a funny rant about an everyday annoyance; actually funny; specific and concrete; sharp and economical; fresh angle.

## Run

```sh
node main.ts
cat /output/entry.txt
```
